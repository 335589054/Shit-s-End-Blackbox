## 1. 分层接口（Kotlin）

### 1.1 Shell 访问层

```kotlin
data class ShellResult(
    val code: Int,
    val stdout: String,
    val stderr: String,
    val timedOut: Boolean = false,
)

interface ShellExecutor {
    /** 同步执行 sh -c 命令；超时返回 timedOut=true 并销毁进程。 */
    fun exec(command: String, timeoutMs: Long = 15_000): ShellResult

    /** 带 stdin 的命令（用于 pm install -S / cat）。 */
    fun execWithInput(command: String, input: ByteArray?, timeoutMs: Long): ShellResult

    /** 把远端文件读成本地 ByteArray（内部用 cat 流）。 */
    fun readFile(path: String, maxBytes: Long = 64L * 1024 * 1024): ByteArray
}
```

实现：`ShizukuShell`（经 `Shizuku.newProcess`，反射）与 `AdbShell`（仅调试，`Runtime.exec`，非 Shizuku 环境不可用）。

约定：

- 所有命令以 `sh -c <command>` 执行；
- stdout/stderr 上限 1 MB，超出截断并标记；
- 非 0 退出码由业务层判断，不自动抛异常；
- 命令中的包名必须经 `sanitizePackage()` 校验（`[A-Za-z0-9._]+`）。

## 2. shell 命令契约

| 目的 | 命令 | 期望 |
|---|---|---|
| 列出包 | `pm list packages -f -u` | 每行 `package:/path=name` |
| 包详情 | `dumpsys package <pkg>` | 解析 versionCode/versionName/flags/signatures |
| 包路径 | `pm path <pkg>` | `package:/data/app/.../base.apk` 多行 |
| 卸载（shizuku 直连） | `app_process ... PackageUninstaller <pkg> <user>` | stdout `OK`/`ERR …` |
| 普通卸载 | `pm uninstall --user 0 <pkg>` | `Success`/`Failure […]` |
| 流式安装 | `pm install -S <size> -r --user 0` + stdin | `Success`/`Failure […]` |
| 禁用 | `pm disable-user --user 0 <pkg>` | `Package … new state: disabled-user` |
| 启用 | `pm enable <pkg>` | `Package … new state: enabled` |
| 强停 | `am force-stop <pkg>` | 空输出，exit 0 |
| appops 读 | `cmd appops get <pkg> <OP>` | `<OP>: <mode>` |
| appops 写 | `cmd appops set <pkg> <OP> <mode>` | 空输出 |
| 撤销权限 | `pm revoke <pkg> <permission>` | 空输出；失败含 `Exception` |
| 网络策略 | `cmd netpolicy add restrict-background-blacklist <uid>` | 空输出 |
| 解除网络策略 | `cmd netpolicy remove restrict-background-blacklist <uid>` | 空输出 |

### 2.1 appops 操作名映射

| Capability | 模式 | OP 名 |
|---|---|---|
| LOCATION 黑 | 禁止 | `FINE_LOCATION`=`ignore`，`COARSE_LOCATION`=`ignore` |
| LOCATION 灰 | 仅前台 | 两者 `foreground` |
| LOCATION 白 | 允许 | 两者 `allow` |
| LOCATION 反卫星 | 精定位禁、粗定位允 | `FINE_LOCATION`=`ignore`，`COARSE_LOCATION`=`allow` |
| SCREEN_RECORD 黑 | 禁止 | `PROJECT_MEDIA`=`deny` |
| SCREEN_RECORD 灰 | 仅前台 | `PROJECT_MEDIA`=`foreground`（不支持时降级 deny） |
| SCREEN_RECORD 白 | 允许 | `PROJECT_MEDIA`=`allow` |

兼容：若 `cmd appops set` 返回 `Unknown operation`，回退尝试 `android:project_media`、`RECORD_AUDIO` 组合，并在结果中标记“部分生效”。

## 3. app_process 入口协议

类：`mai.solium.shitsendblackbox.core.PackageUninstaller`

```
用法: app_process /system/bin mai.solium.shitsendblackbox.core.PackageUninstaller <pkg> <userId> [--keep-data]
环境: CLASSPATH=<本应用 APK 路径>
身份: 必须 uid=2000（shell），否则输出 ERR_NOT_SHELL 并退出 2
输出: 单行
  OK <pkg>
  ERR_NOT_SHELL
  ERR_ARG
  ERR_NO_PM
  ERR_METHOD <signature>
  ERR_INVOKE <exception class>: <message>
退出码: 0 成功；2 身份/参数错误；3 调用失败
```

反射适配顺序：

1. `deletePackageAsUser(String, int, IPackageDeleteObserver, int, int)`
2. `deletePackageAsUser(String, IPackageDeleteObserver, int, int)`
3. `deletePackage(String, IPackageDeleteObserver, int)`

参数 `versionCode` 固定传 `-1`；`userId` 由调用方传 `0`；flags 固定 `5`（`DELETE_KEEP_DATA(1) | DELETE_SYSTEM_APP(4)`）。

## 4. 持久化格式

### 4.1 `files/zones.json`

```json
{
  "version": 1,
  "default": "white",
  "apps": {
    "com.mobiletools.systemhelper": {
      "zone": "black",
      "updatedAt": 1762700000000,
      "note": "联通 DM 组件"
    }
  }
}
```

- `zone` ∈ `black|gray|white`；
- 未记录的应用返回 `default`；
- 写入采用“临时文件 + rename”保证原子性。

### 4.2 `files/backups/<pkg>/meta.json`

```json
{
  "packageName": "com.mobiletools.systemhelper",
  "versionCode": 301,
  "versionName": "3.0.1",
  "signatureSha256": "ab12…",
  "userId": 0,
  "systemApp": true,
  "enabled": true,
  "installer": null,
  "backupAt": 1762700000000,
  "base": { "name": "base.apk", "size": 4096000, "sha256": "…" },
  "splits": [
    { "name": "split_config.x86_64.apk", "size": 102400, "sha256": "…" }
  ]
}
```

- 备份目录权限 `700`；文件 `600`；
- 校验失败（大小或 SHA-256 不符）时 `meta.json` 标记 `"verified": false`，禁止删除。

### 4.3 `files/blocklist_user.json`

```json
{
  "version": 1,
  "disabledGroups": ["xiaomi-sec"],
  "disabledDomains": ["tracking.miui.com"],
  "extraDomains": ["evil.example.com"],
  "extraIps": ["203.0.113.9", "198.51.100.0/24"]
}
```

### 4.4 `files/settings.json`

```json
{
  "vpnEnabled": false,
  "upstreamDns": "223.5.5.5",
  "antiSatellite": false,
  "autoReapply": true,
```

## 5. Stub APK 规格

二进制 `AndroidManifest.xml`（AXML）字段：

| 字段 | 值 |
|---|---|
| `manifest@package` | 目标包名（原始字符串属性，无资源 ID） |
| `manifest@versionCode` | `25565` |
| `manifest@versionName` | `"25565"` |
| `uses-sdk@minSdkVersion` | `26` |
| `uses-sdk@targetSdkVersion` | `26` |
| `application@hasCode` | `false` |
| `application@enabled` | `false` |
| `application@allowBackup` | `false` |
| `application@label` | 无（避免资源引用） |
| `application@icon` | 无 |

- 无组件、无权限、无 `classes.dex`、无 `resources.arsc`；
- 使用 `assets/stub.p12` 签名（v1 + v2）；
- 生成后自检：`aapt2 dump badging` 等价解析（读取 AXML 回验）包名/版本。

## 6. DNS / IP 规则匹配

- 域名归一化：小写、去尾点、IDN 转 punycode（`java.net.IDN`）；
- 匹配方式：`suffix`（`example.com` 命中 `a.example.com` 与 `example.com`）；
- 例外：`localhost`、`*.local` 不拦截；
- IP：单地址或 CIDR，IPv4 前缀 0–32，IPv6 前缀 0–128；
- 同一域名同时出现在启用组与用户禁用列表时，**用户禁用优先**。
