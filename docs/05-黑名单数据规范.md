# 05 · 黑名单数据规范

- 版本：v0.1
- 文件：`app/assets/blocklist.json`（内置种子）、`files/blocklist_user.json`（用户增量）

---

## 1. 结构

```json
{
  "version": 1,
  "updated": "2026-11-09",
  "groups": [
    {
      "id": "unicom-dm",
      "name": "联通 DM / 系统组件",
      "note": "上报 IMEI/IMSI/ICCID、基站、应用使用与流量",
      "domains": ["dm.wo.com.cn"],
      "ips": ["10.0.0.172", "10.0.0.200"],
      "enabled": true
    }
  ]
}
```

### 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `version` | int | 是 | 结构版本，当前 1 |
| `updated` | string | 是 | ISO 日期 |
| `groups[].id` | string | 是 | 稳定标识，用户配置按此引用 |
| `groups[].name` | string | 是 | 展示名 |
| `groups[].note` | string | 否 | 来源/行为说明 |
| `groups[].domains` | string[] | 否 | 域名，后缀匹配 |
| `groups[].ips` | string[] | 否 | IPv4/IPv6 单地址或 CIDR |
| `groups[].enabled` | bool | 是 | 默认启用状态（用户可覆盖） |

### 约束

- 域名：小写、不含协议/路径/端口、不含 `*`；IDN 用 punycode；
- IP：标准写法；CIDR 前缀合法；
- 同一域名可出现在多个组，去重后仅保留一次；
- 组内空数组允许，但不得整组为空；
- 总条目上限：域名 5000、IP 2000（超出拒绝导入并提示）。

---

## 2. 用户覆盖

`blocklist_user.json`：

```json
{
  "version": 1,
  "disabledGroups": [],
  "disabledDomains": [],
  "extraDomains": [],
  "extraIps": []
}
```

优先级（从高到低）：

1. `extraDomains` / `extraIps`：强制拦截；
2. `disabledDomains`：强制放行（覆盖组）；
3. `disabledGroups`：整组关闭；
4. 组默认 `enabled`。

---

## 3. 导入/导出

- 导入：选择 `.json` 文件（SAF），按上表校验；非法条目跳过并报告数量；
- 导出：合并后的完整规则（含用户增量）为 JSON，便于分享；
- 兼容：接受仅含 `domains`/`ips` 数组的简化文件，自动包装为 `imported-<timestamp>` 组。

## 5. 维护流程

1. 新增数据需注明来源（APK 静态字符串、抓包、公开报告）；
2. 每条组至少一个域名或 IP，附 `note`；
3. 合并前跑 `tools/validate_blocklist.py`（构建脚本调用）：
   - JSON 合法、字段类型正确；
   - 域名/IP 格式合法；
   - 无重复、无空组、无超限；
4. 版本号递增，`updated` 更新；
5. 发布包内置最新种子，用户增量不随版本覆盖。

---

## 6. 已知绕过

- DoH / DoT：直接加密查询，DNS 污染无效；可另加 DoH 服务 IP 到 IP 黑名单。
- 硬编码 IP：仅当该 IP 在规则中才被丢包。
- 代理 / VPN 嵌套：本应用 VPN 无法覆盖另一 VPN 的流量。
- 系统级特权通道：厂商组件可绕过 appops（如直接 netd / raw socket），本工具无法完全阻止，需配合卸载/隔离。
